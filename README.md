Exploratory data analysis, data cleaning and business analytics in Python (pandas, matplotlib, seaborn).

Part of **[urvee-data-lab](https://github.com/urvee-data-lab)** - my full archive of data science and analytics work, organised by topic.

## Projects

| # | Project | Problem | Key methods | Result |
|---|---------|---------|-------------|--------|
| 1 | [Google Play Store Market Analysis](google-playstore-data-munging) | Clean ~10.8K app listings and analyse the market for a client planning an app launch | Data cleaning, EDA, confidence interval, Welch t-test, Mann–Whitney | 9,659 clean apps; 8 business questions answered; launch recommendations |

## How this repo is organised

Each project lives in its own folder:

```
project-name/
├── README.md        # problem, approach, results
├── notebook.ipynb   # full analysis, runs top to bottom
├── data/            # dataset (or a sample + link if large)
└── figures/         # charts used in the README
```

Larger projects have their own repository and are linked from the table above.
